# 視覺設計：匿名聊天室

依據 `docs/architecture.md` 第 7 節「畫面清單」。風格沿用 P4 共識：酒紅主色、淡黃點綴、白／淺灰底色、深色模式跟隨系統。**手機優先**，電腦加寬成側邊欄版面。

## 1. 設計原則

- 手機優先：先設計窄螢幕，寬螢幕再加側邊欄
- 簡潔、溫暖，不花俏；內容（訊息）是主角
- 觸控目標至少 44px 高；字級內文 16px 以上（避免 iOS 輸入時自動放大）
- 所有元素都要能用鍵盤操作，狀態不只靠顏色表達

## 2. 色彩

| 用途 | 淺色 | 深色 |
|---|---|---|
| 主色（標題列、送出鈕、自己的訊息底） | `#9F0050` | `#C2417A` |
| 主色上的文字 | `#FFFFFF` | `#FFFFFF` |
| 點綴（連線狀態條、強調標示） | `#FFE66F` | `#FFE66F`（文字用深色 `#3A2F00`） |
| 次要強調（連結感、少量使用） | `#C65213` | `#E0783A` |
| 頁面底色 | `#FFFFFF` | `#14110F` |
| 面板／側邊欄底色 | `#F5F5F5` | `#1E1A18` |
| 他人訊息泡泡 | `#F5F5F5` | `#2A2523` |
| 內文文字 | `#222222` | `#EEEEEE` |
| 次要文字（時間、提示） | `#6B6B6B` | `#A8A29E` |
| 錯誤 | `#B3261E` | `#F2B8B5` |

代號顏色：依代號字串算出固定的色相，從一組約 10 色、與底色對比足夠的色盤中選取，同一代號永遠同色（淺色與深色各一組）。

## 3. 字體與間距

- 字體：系統字體（`"Noto Sans TC", system-ui, sans-serif`），不載入外部字型，載入快
- 字級：標題 18px／內文 16px／次要 13px
- 間距單位 4px 的倍數；訊息之間 8px，同一人連續訊息之間 2px
- 圓角：泡泡 12px、按鈕與輸入框 8px

## 4. 畫面 A：輸入代號

置中卡片，寬度手機滿版（左右留 16px）、電腦最大 360px。

```
┌─────────────────────────┐
│        匿名聊天室         │  標題（主色文字）
│  不用登入，取個代號就能聊  │  次要文字
│                         │
│  代號                    │
│  ┌───────────────────┐  │
│  │ 小明（預填上次代號） │  │  輸入框，maxlength 12
│  └───────────────────┘  │
│  錯誤訊息（有錯才出現）    │  紅字＋圖示
│  ┌───────────────────┐  │
│  │       進入         │  │  主色大按鈕
│  └───────────────────┘  │
└─────────────────────────┘
```

行為：
- 進入畫面自動聚焦輸入框，Enter 等同按「進入」
- 錯誤文字：空白、超過 12 字、「這個代號已經有人用了，請換一個」
- 按「進入」後按鈕顯示處理中並暫時停用，避免重複送出

## 5. 畫面 B：聊天室

### 5-1 手機（窄螢幕）

```

│  ── 10月13日 ──          │ 日期分隔線
```

### 5-2 電腦（寬度 ≥ 768px）

左側訊息區、右側固定寬 240px 的線上名單側邊欄，頂端列只顯示聊天室名稱與「離開」。

```
┌───────────────────────────────┬──────────┐
│ 匿名聊天室                 離開 │ 線上（5） │
├───────────────────────────────┤ 小明（你） │
│ 訊息區                         │ Amy      │
│                               │ Bob      │
├───────────────────────────────┤ …        │
│ 輸入框                  [送出] │          │
└───────────────────────────────┴──────────┘
```

## 6. 元件與行為

| 元件 | 說明 |
|---|---|
| 頂端列 | 聊天室名稱、人數（手機可點開名單）、「離開」按鈕 |
| 連線狀態條 | 斷線時顯示淡黃底深色字「連線中斷，重新連線中…」；連回後自動消失 |
| 線上名單 | 每列一個代號，前面小圓點為該代號固定色；自己標示「（你）」；超過高度可捲動 |
| 訊息泡泡 | 他人：靠左、淺灰底；自己：靠右、主色底白字；同一人連續訊息合併，只在第一則顯示代號；時間只顯示時:分 |
| 進出提示 | 訊息間插入的一行灰色小字置中，如「小明 加入了聊天室」 |
| 日期分隔線 | 跨日時出現一條細線加日期 |
| 保留說明 | 訊息區頂端灰色小字「訊息只保留最近的 200 則」 |
| 輸入框 | 多行自動增高（最多約 4 行）；超過 500 字禁止再輸入；顯示「已輸入／500」，剩餘不足 50 字時變為強調色 |
| 送出按鈕 | 輸入為空時停用；斷線時整個輸入區停用但保留已打的字 |
| 離開按鈕 | 按下直接離開並釋出代號，回到畫面 A |

鍵盤：電腦 Enter 送出、Shift+Enter 換行；手機 Enter 換行，用送出按鈕。

## 7. 狀態

| 狀況 | 畫面表現 |
|---|---|
| 剛進入、載入最近 50 則 | 訊息區顯示簡單的載入中提示 |
| 聊天室還沒有訊息 | 顯示「還沒有人說話，來打個招呼吧」 |
| 斷線 | 狀態條出現、輸入區停用、已打的字保留 |
| 重新連線 | 狀態條消失，自動補上漏掉的訊息 |
| 代號被佔用／格式錯誤 | 輸入框下方紅色錯誤文字，輸入框邊框變紅 |
| 新訊息到來但使用者正在看舊訊息 | 不強制捲動，底部出現「有新訊息 ↓」按鈕，點了捲到底 |

## 8. 無障礙與動態

- 文字與底色對比至少 4.5:1（淺色與深色都要）
- 新訊息區域設為 `aria-live="polite"`，讀屏軟體會唸出；錯誤文字用 `role="alert"`
- 按鈕與輸入框有明顯的鍵盤聚焦外框
- 動畫只用在展開名單與新訊息淡入，各約 150ms；遵守系統的「減少動態」設定
- 使用者輸入的內容一律當純文字顯示（見架構文件第 9 節）

## 9. 給 P6 前端實作的備註

- 色彩、間距、圓角請做成 CSS 變數，深色模式用 `prefers-color-scheme` 切換
- 畫面元素要和架構文件第 7 節一一對應，不可少
- 畫面程式只透過 `ChatService` 與後端溝通，階段一先接 `MockChatService`
